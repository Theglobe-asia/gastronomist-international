# Contributing to Gastronomist International

Thank you for your interest.

This project is **curated and controlled**. Contributions are selective and guided.

---

## Contribution Policy

### Allowed
- Bug reports
- Copy or content suggestions
- Performance optimizations (approved scope only)
- Accessibility improvements
- Documentation improvements

### Not Allowed
- Design changes without approval
- UI/UX refactors
- Dependency upgrades without request
- Structural rewrites
- “Opinionated” refactors

---

## Workflow Rules (Strict)

- ❌ No guessing
- ❌ No touching files outside the explicit task scope
- ✅ Always work from locked baseline files
- ✅ One file at a time
- ✅ Full copy-pasteable files only
- ✅ Windows-compatible commands only
- ✅ Commit messages must be descriptive

---

## Submitting Changes

1. Open an issue describing the proposal
2. Wait for approval and scope definition
3. Submit changes exactly within scope
4. Include:
   - File(s) changed
   - Reason for change
   - Expected outcome

---

## Code Style

- Next.js App Router
- Functional React components
- Tailwind CSS (no inline styles unless necessary)
- Framer Motion for animation
- Clean, readable, production-grade code

---

By contributing, you agree that all accepted contributions become part of Gastronomist International.
